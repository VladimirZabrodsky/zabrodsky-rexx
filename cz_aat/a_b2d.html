ZE SOUSTAVY O JINÉM ZÁKLADU DO DEKADICKÉ

Nechť B > 1 je kladné číslo (základ). Každé kladné celé číslo X můžeme jednoznačně vyjádřit posloupností N-číslic <DN-1, DN-2, ..., D1, D0>, kde číslice DJ patří do intervalu 0 <= DJ <= B - 1, pro všechna J (viz [1], s. 12.). Číslo X má dekadickou hodnotu:

Y = DN-1 * BN-1 + DN-2 * BN-2 + ... D1 * B1 + D0 * B0

Abychom nemuseli znovu a znovu přepočítávat mocniny B, použijeme trik známý jako Hornerovo pravidlo (viz [2], p. 33.). S jeho využitím hodnotu polynomu stupně N vyčíslíme pomocí jenom N-1 násobení a N sčítání. V jazyce REXX je X znakový řetězec. Pro přístup k jednotlivé (J-té) číslici můžeme použít vestavěnou funkci jazyka SUBSTR:   

B_N2D: procedure
parse arg X, B
N = LENGTH(X)
Y = 0
do J = 1 to N
  Y = Y * B + SUBSTR(X, J, 1)
end
return Y
Funkci B_N2D(X, B) lze použít pouze pro základ B = 2 až 9 (Binary až Nonary, odtud název funkce B_N2D). Pro základy B > 9 použijeme následující funkci ANYBASE2D(X, B) s parametrem X >= 0, kde X je přirozené číslo vyjádřené v číselné soustavě o základu B; a s parametrem B, kde 2 <= B <= 16. Funkce vrací desítkové číslo Y, pro něž platí: Y10 = XB.   
ANYBASE2D: procedure
parse arg X, B
Digit = "0123456789ABCDEF"
do I = 1 to LENGTH(Digit)
  Figure = SUBSTR(Digit, I, 1)
  Dig.Figure = I - 1
end
N = LENGTH(X)
Y = 0
do J = 1 to N
  K = SUBSTR(X, J, 1)
  Y = Y * B + Dig.K
end
return Y

A jakou hodnotu numeric digits zvolit?

Podle [3], s. 22, má-li celé číslo X právě N číslic v soustavě o základu B, potom v soustavě o základu 10 bude mít stejný počet číslic vynásobený konstantou (faktorem):
CEILING(LN(B)/LN(10)). Hodnoty tohoto faktoru jsou: 


Základ           Faktor
 2, ..., 10        1
11, ..., 16        2

Z DEKADICKÉ SOUSTAVY DO SOUSTAVY O JINÉM ZÁKLADU

Je dáno číslo, X, které chceme konvertovat do číselné soustavy o základu B. Pro provedení této akce se používá algoritmus (viz [4], s. 53):
1. Nejpravější číslici výsledku Y určíme jako zbytek po dělení X // B.
2. Hodnotu X zaměníme hodnotou celočíselného podílu X % B.
3. Opakujeme kroky 1 and 2 až X nabyde hodnoty nula, X = 0.
Následující zápis funkce v jazyce REXX nevyžaduje ani použití zásobníku, ani rekurze. Můžeme ji využít při převodu do soustavy o základu B = 2, ..., 9:   

D2B_N: procedure
parse arg X, B
if X = 0 then return 0
Y = ""
do while X > 0
  Y = X // B || Y
  X = X % B
end
return Y
Obecně, pro B = 2, ..., 16 je určena následující funkce D2ANYBASE(X, B) s parametry: X >= 0 je přirozené číslo v desítkové soustavě; parametr B je báze, pro niž platí 2 <= B <= 16. Funkce vrací hodnotu Y takovou, že YB = X10.   
D2ANYBASE: procedure
parse arg X, B
if X = 0 then return 0
Digit = "0123456789ABCDEF"
Y = ""
do while X > 0
  Rem = X // B
  Y = SUBSTR(Digit, Rem + 1, 1) || Y
  X = X % B
end
return Y

Z JEDNÉ ČÍSELNÉ SOUSTAVY DO DRUHÉ

Následující program převede číslo X > 0 vyjádřené v číselné sopustavě Bi na číslo Y v číselné soustavě Bo, tak že platí YBo = XBi, pro 2 <= Bi, Bo <= 16 a Bi <> Bo. Převod se provede funkcí ANYBASE2ANYBASE(X, Bi, Bo):

  
ANYBASE2ANYBASE: procedure
parse arg X, Bi, Bo
return D2ANYBASE(ANYBASE2D(X, Bi), Bo)
Sofistikovaná verze ANYBASE2ANYBASE(X, Bi, Bo) využívá metody popsané v [5], kapitola 4.1.3:

Převod z číselné soustavy o základu 2 do číselné soustavy o základu 2k: Bity čísla vyjádřeného v binární soustavě se základem 2 uspořádáme do bloků po k bitech. Začneme zprava a případně doplníme zleva potřebný počet nul. Každý blok potom konvertujeme na číslo vyjádřené v číselné soustavě o základu 2k.
Příklad: Převod z binární do osmičkové soustavy provedeme tak, že zápis binárního čísla rozdělíme zprava na bloky po třech bitech. U nejlevějšího bloku případně doplníme vedoucí nuly. Každý blok převedeme na osmičkové číslo. Při převodu nepočítáme, ale hodnoty převezmeme z předpřipravené tabulky. Podobně u převodu z binárního na hexadecimální číslo použijeme čtyřbitové bloky.

Převod z číselné soustavy o základu 2k do binární soustavy (základ 2): v čísle vyjádřeném v číselné soustavě o základu 2k převádíme každou číslici do bloku bitů o k bitech.

Obdobně postupujeme v případě převodu ze soustavy o základu 3 do soustavy o základu 32 a naopak.

Dále uvedená funkce DIRECTCONVERT(X, Bi, Bo) vezme vstupní řetězec X, reprezentující přirozené číslo vyjádřené v soustavě o základu Bi a převede je do sosutavy o základu Bo. Funkce vrací řetězec Y, YBo = XBi, pro páry hodnot
{Bi, Bo}: {2, 4}, {4, 2}, {2, 8}, {8, 2}, {3, 9}, {9, 3}, {2, 16}, {16, 2}.
Asociativní pole LookT. je předpřipravenou tabulkou hodnot.

PŘÍKLAD
Máme převést binární číslo 10010011 do hexadecimální soustavy. Pro Bi = 2, Bo = 16 funkce DIRECTCONVERT vytvoří pole: 
LookT.2.16 = 4
LookT.2.16.0000 = 0; LookT.2.16.0001 = 1; LookT.2.16.0010 = 2; LookT.2.16.0011 = 3
LookT.2.16.0100 = 4; LookT.2.16.0101 = 5; LookT.2.16.0110 = 6; LookT.2.16.0111 = 7
LookT.2.16.1000 = 8; LookT.2.16.1001 = 9; LookT.2.16.1010 = "A"; LookT.2.16.1011 = "B"
LookT.2.16.1100 = "C"; LookT.2.16.1101 = "D"; LookT.2.16.1110 = "E"; LookT.2.16.1111 = "F"
Bude se postupovat zprava a pro každou čtveřici číslic (čtveřici bitů) se určí její hexadecimální ekvivalent. Kolik bitů máme brát je uloženo v proměnné LookT.2.16 (tj. 4). Výsledek se vypočte přímo, bez výpočtu: LookT.2.16.1001 || LookT.2.16.0011 = 93.   
DIRECTCONVERT: procedure
parse arg X, Bi, Bo
/* Create Lookup Table */
do K = 2 to 4 /* number of bits for base = 2 ** K */
  Base2K = 2 ** K
  LookT.2.Base2K = K
  LookT.Base2K.2 = 1
  do I = 0 to Base2K - 1
    Xi = D2ANYBASE(I, Base2K)
    Bin= RIGHT(D2ANYBASE(I, 2), K, "0")
    LookT.2.Base2K.Bin = Xi
    LookT.Base2K.2.Xi = Bin
   end
end
do K = 2 to 2 /* number of bits for base = 3 ** K */
  Base3K = 3 ** K
  LookT.3.Base3K = K
  LookT.Base3K.3 = 1
  do I = 0 to Base3K - 1
    Num = RIGHT(D2ANYBASE(I, 3), K, "0")
    LookT.3.Base3K.Num = I
    LookT.Base3K.3.I = Num
  end
end
/* end of Lookup Table creating */
N = LENGTH(X)
Group = LookT.Bi.Bo
Length_Group = N // Group
if Length_Group > 0 
  then do
    N = N + Group - Length_Group
    X = RIGHT(X, N, "0")
  end
Y = ""
do Index = N - Group + 1 to 1 by -Group
  Figure = SUBSTR(X, Index, Group)
  Y = LookT.Bi.Bo.Figure || Y
end
return Y
Pro dvojice hodnot [Bi, Bo]: [4, 8], [8, 4], [4,16], [16, 4], [8, 16], [16, 8] 
DIRECTCONVERT(DIRECTCONVERT(X, Bi, 2), 2, Bo)
Výpočet ANYBASE2ANYBASE(X, Bi, Bo) může být urychlen pro některé konkrétní hodnoty Bi a Bo (zjištěno experimentálně). Finální verze funkce vypadá takto:   
ANYBASE2ANYBASE: procedure
parse arg X, Bi, Bo
TestQOX. = 0
TestQOX.4 = 1; TestQOX.8 = 1; TestQOX.16 = 1
Test2K. = 0
Test2K.2 = 1; Test2K.4 = 1; Test2K.8 = 1; Test2K.16 = 1
Test3K. = 0
Test3K.3 = 1; Test3K.9 = 1
select
  when Bi = Bo then return X
  when (TestQOX.Bi & TestQOX.Bo)
  /* Bi, Bo from {4, 8, 16}, i.e. Quaternary, Octal, heXadecimal */
    then return DIRECTCONVERT(DIRECTCONVERT(X, Bi, 2), 2, Bo)
  when (Test2K.Bi & Test2K.Bo) | (Test3K.Bi & Test3K.Bo)
  /* Bi, Bo either from {2, 2 ** K}, or from {3, 3 ** K} */
    then return DIRECTCONVERT(X, Bi, Bo)
  when Bi = 2 then return D2ANYBASE(X2D(B2X(X)), Bo)
  when Bo = 2 then return X2B(D2X(ANYBASE2D(X, Bi)))
  when Bo = 16 then return D2X(ANYBASE2D(X, Bi))
  when Bo = 10 then return ANYBASE2D(X, Bi)
  otherwise return D2ANYBASE(ANYBASE2D(X, Bi), Bo)
end
