NUMBER π

Problem

Compute the number π to thousand decimal places.


Algorithm

Algorithm of J. M. Borwein and P. B. Borwein for computation of π number starts with the initializations X = SQRT(2); Pi = 2 + X; Y = SQRT(X) and then repeats the iteration 

X = 0.5 * (SQRT(X) + 1 / SQRT(X)
Pi = Pi * (X + 1) / (Y + 1)
Y = Y * (SQRT(X) + 1 / SQRT(X)) / (Y + 1)

Implementation

Unit: internal function, external function without procedure statement
 
Interface: SQRT function
 
Parameter: a positive integer P - number of digits of π, implicit P = 9
 
Returns: the first P significant decimal digits of π, default is 9   


PI: procedure
parse arg P
if P = "" then P = 9; numeric digits P
X = SQRT(2, P); Pi = 2 + X
Y = SQRT(X, P); X = Y
do forever
  X = 0.5 * (X + 1 / X)
  NewPi = Pi * (X + 1) / (Y + 1)
  if Pi = NewPi then return Pi
  Pi = NewPi
  X = SQRT(X, P)
  Y = (Y * X + 1 / X) / (Y + 1)
end
There is an another way to obtain the value of the number π: we can compute the number π only once and save its value into the text of the function. The following PICONST function can be used to computing of the first P decimal digits of π, for P = 1, ..., 200. It was created automatically by the program, see Technique: Beforehand computed constants.     

PICONST: procedure; V = ''
