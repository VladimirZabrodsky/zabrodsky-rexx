EULER'S CONSTANT γ


This number is defined: γ = H.N - LN(N) where N goes to infinity and the N-th harmonic number is defined to be the sum

H.N = 1 + (1/2) + (1/3) + ... + (1/N)


Algorithm

We use the formula

LN(N) + γ + chyba = X/FACT(1) - X**2/(2*FACT(2)) + X**3/(3*FACT(3)) ...

where FACT is the factorial function and L. Euler proved that error = O(EXP(-X)/X).


Implementation

Unit: program
 
Interface: the LN function
 
Result: program displays on the screen first 60 significant decimal digits of the γ constant   


X = 130; W=500; P = 130
numeric digits P
N = X; F = 1; D = 1; S = X
do K = 2 to W
  N = - N * X; F = F * K; D = F * K
  S = S + N / D
end
say S - LN(X, P)
This program requires about one minute of processing time. There is an another way to obtain the value of the γ constant: we can compute the γ number only once and save its value into the text of the function. The following GAMMA_CONST function can be used to compute the first P decimal digits of γ, for P = 1, ..., 60.   

GAMMA_CONST: return,
"0.5772156649015328606065120900" ||,
"824024310421593359399235988058"
